# Okoya System

This project contains two Flask applications:

## 1. Weighbridge App
Handles truck weight records and transactions.

## 2. Food Staff Management App
Manages workers, attendance, and salary.

## Tech Stack
- Flask
- PostgreSQL
- SQLAlchemy

## Deployment Plan
- Hosting: Railway
- Database: Neon
- Domain: okoyafood.com
